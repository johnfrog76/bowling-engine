# bowling-engine

Framework-free ten-pin bowling scoring engine — extracted from the
[CSS Wasteland](https://css-wasteland.com) bowling decks.

Full source, tests, and docs are on their way. In the meantime, the two
decks that link here are live:

- [Bowling Ball Coach](https://css-wasteland.com) — the mechanics of scoring
- [League Night](https://css-wasteland.com) — Channel 14 covers the dev league

More soon.
